# OpticMart Styling Guidelines

- **Domain**: opticmart.shop
- **Brand Name**: OpticMart (never OpticsMart)
- **Typography Rule**:
  - **Never use spacing between letters** on OpticMart (`opticmart.shop`).
  - Do not apply `tracking-*` (e.g. `tracking-wider`, `tracking-widest`, `tracking-[...]`) or CSS `letter-spacing` to hero sections, headings, badges, or body text.
