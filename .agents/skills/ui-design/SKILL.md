# UI Design & Styling Standards

## Typography & Letter Spacing
1. **Hero Section Rule**:
   - **Never use spacing between letters** in the hero section (no `letter-spacing`, `tracking-wider`, `tracking-widest`, or custom tracking like `tracking-[0.2em]`).
   - Keep typography natural, legible, and compact.

2. **OpticMart (`opticmart.shop`) Specifics**:
   - Strictly avoid letter-spacing (`tracking`) across hero banners, badges, headings, and component titles.
   - Use standard font tracking (`tracking-normal` or Tailwind default) for all badges, categories, and hero elements.
